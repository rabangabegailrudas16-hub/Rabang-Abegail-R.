
# Laboratory 05 - Cloud Data Engineer

## Mission Overview

The mission involved creating a proof-of-concept cloud storage environment for a photo-sharing application. MinIO was deployed as an S3-compatible Object Storage server, followed by the creation of a bucket for storing sample user-uploaded files.

## Objectives

- Identify the differences between major cloud storage types.
- Determine an appropriate storage solution for large collections of images.
- Deploy an Object Storage server with Docker.
- Access and manage the MinIO Web Console.
- Create an object storage bucket.
- Upload and verify a sample object.
- Record the technical deployment process.

## Tools Used

- GitHub
- KillerCoda
- Ubuntu Linux
- Docker
- MinIO
- Web Browser
- Linux Terminal

## Skills Learned

- Managing files and folders in a GitHub repository.
- Writing technical documentation using Markdown.
- Running Docker commands in Linux.
- Deploying a containerized storage service.
- Managing buckets and objects in MinIO.
- Verifying running containers with Docker commands.
- Using screenshots as deployment evidence.
