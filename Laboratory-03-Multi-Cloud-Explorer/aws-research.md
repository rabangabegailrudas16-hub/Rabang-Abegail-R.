# Amazon Web Services (AWS)

## Overview
It has launched by Amazon in 2006, **AWS** is a comprehensive cloud computing platform offering scalable computing power, database storage, content delivery, and networking capabilities.

## Global Infrastructure
AWS operates on a globally distributed network of **Regions** and **Availability Zones (AZs)**, engineered to deliver high availability, redundancy, and fault tolerance.

## Management & Tools
* **AWS Management Console:** A web-based GUI for accessing and managing AWS resources.

## Core Services
| Service | Type | Description |
| :--- | :--- | :--- |
| **EC2** | Compute | Scalable virtual servers in the cloud |
| **S3** | Storage | High-durability object storage |
| **RDS** | Database | Managed relational database service |
| **VPC** | Networking | Isolated virtual network environment |

## Key Advantages
* **Breadth of Services:** Extensive catalog covering AI/ML, analytics, IoT, and core infrastructure.
* **Scalability:** Elastic architecture that scales up or down based on demand.
* **Global Footprint:** Multi-region deployment capabilities for low latency.

## Common Use Cases
* Hosting enterprise web and mobile applications
* Building scalable SaaS applications
* Big data analytics and secure cloud storage backups
