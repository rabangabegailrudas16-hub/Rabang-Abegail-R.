# Microsoft Azure

## Overview
It has launched on Microsoft in 2010, **Azure** is a great cloud computing platform providing a great of services including compute, storage, networking, and analytics.

## Global Infrastructure
Azure features an extensive global network of **Regions** and **Availability Zones (AZs)**, built to maximize performance, reliability, and low-latency delivery.

## Management & Tools
* **Azure Portal:** A unified, web-based console designed to build, manage, and monitor cloud services.

## Core Services
| Service | Type | Description |
| :--- | :--- | :--- |
| **Virtual Machines** | Compute | On-demand, scalable virtualized computing resources |
| **Blob Storage** | Storage | Massively scalable object storage for unstructured data |
| **Azure SQL Database** | Database | Fully managed relational database engine with automated scaling |
| **Virtual Network (VNet)** | Networking | Isolated, secure private network environment in the cloud |

## Key Advantages
* **Seamless Ecosystem:** Native integration with Windows Server, Active Directory, and Microsoft 365.
* **Hybrid Cloud Focus:** Superior hybrid capabilities via Azure Arc for hybrid and multi-cloud management.
* **Enterprise Security:** Multi-layered security controls and extensive compliance certifications.

## Common Use Cases
* Migrating on-premises Microsoft infrastructure to the cloud
* Developing and hosting enterprise-grade applications
* Hybrid cloud deployments and disaster recovery/backup strategies
