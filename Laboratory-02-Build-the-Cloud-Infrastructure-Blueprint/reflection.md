Mission Reflection

1. Which cloud infrastructure component do you think is the most important? Why?
   I think the most important cloud infrastructure component is compute resources because they allow applications and services to run. Without compute resources, the system would not be able to process tasks or respond to users. It works together with storage and networking to provide a complete cloud environment.

2. How does Linux support cloud computing?
   Linux supports cloud computing by providing a reliable operating system for cloud servers. It allows users and cloud engineers to manage resources, run commands, monitor the system, and configure services. In the KillerCoda environment, I was able to use Linux commands to investigate the server's hardware and software information.

3. Why is technical documentation important before deploying infrastructure?
   Technical documentation is important because it helps engineers understand and organize the infrastructure before deployment. It provides a clear record of the resources, configurations, and decisions made during the planning process. Good documentation can also make troubleshooting and future maintenance easier.

4. What new skills did you learn during this laboratory activity?
   During this laboratory activity, I learned how to investigate a Linux cloud server and identify its compute, storage, networking, and operating system resources. I also improved my skills in using Linux commands, creating Markdown documentation, comparing cloud providers, and organizing files in GitHub.

5. How has your GitHub portfolio improved after completing this mission?
   My GitHub portfolio became more organized and informative after completing this mission. I added a new laboratory folder containing technical reports, cloud component information, provider comparisons, a reflection, and screenshots. This helped me understand how important proper documentation and organized project files are for a cloud computing portfolio.
