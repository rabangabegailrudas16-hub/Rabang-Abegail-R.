# Cloud Provider Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud |
|---|---|---|---|
| *Compute* | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| *Storage* | Amazon S3 | Azure Storage | Cloud Storage |
| *Networking* | Amazon VPC | Azure Virtual Network | Google Cloud VPC |
| *Identity & Access Management* | AWS IAM | Microsoft Entra ID / Azure RBAC | Google Cloud IAM |

### 1. Which provider offers the broadest range of services?

AWS offers a very wide range of cloud services, including computing, storage, networking, databases, security, and other services. It is a good choice for organizations that need many different cloud services.

### 2. Which would you recommend for an organization primarily using Microsoft products?

I would recommend Microsoft Azure because it works well with Microsoft products and technologies. It also provides tools for managing users, permissions, and cloud resources.

### 3. Which is widely recognized for AI, ML, and Kubernetes?

Google Cloud is widely recognized for its work in artificial intelligence and machine learning. It also has strong support for Kubernetes and container-based applications.

### 4. What similarities did you observe?

AWS, Microsoft Azure, and Google Cloud all provide compute, storage, networking, and identity management services. All three allow organizations to use cloud resources without having to maintain all the physical hardware themselves.
