# Reflection

As an it student, for me the docker are containers run more efficiently than virtual machines because they don’t require 
a separate full operating system. Virtual machines take more time to start since they load 
an entire OS, while containers launch faster by utilizing the host system.

Port mapping like -p 8080:80 enables access to the container from the host computer. 
Without this configuration, the service running inside the container would not be accessible outside of it.

Using docker rm removes the container together with any data stored inside it. 
This means containers are temporary unless persistent storage is set up.

Containerization improves collaboration between developers and IT teams 
by maintaining a consistent environment, ensuring applications behave the same across different platforms.
