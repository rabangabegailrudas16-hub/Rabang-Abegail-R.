Cloud Infrastructure Components

Compute Resources

Compute resources provide the processing power needed to run applications and perform tasks in the cloud.

Storage Resources

Storage resources are used to save operating system files, applications, data, and other information.

Networking Resources

Networking resources allow systems, users, and services to communicate with each other through network connections.

Operating System

The operating system manages the computer's hardware and software resources. In this laboratory, the Linux environment was used to investigate and manage the cloud server.

Linux Commands Executed

The following Linux commands were used to investigate the cloud server:

- "uname -a" – checks system and kernel information
- "lscpu" – displays CPU information
- "free -h" – displays RAM information
- "df -h" – checks disk usage and capacity
- "lsblk" – displays storage devices
- "hostname" – displays the hostname
- "ip addr" – displays network and IP address information
- "mount" – displays mounted file systems
